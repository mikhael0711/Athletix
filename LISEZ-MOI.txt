ATHLETIX V2 — publication GitHub Pages
1. Décompressez le ZIP.
2. Dans le dépôt GitHub athletix, remplacez les anciens fichiers par TOUS les fichiers de ce dossier à la racine.
3. Conservez Settings > Pages > Deploy from a branch > main > /(root).
4. Attendez la fin de GitHub Actions, puis rechargez https://mikhael0711.github.io/Athletix/
5. Sur Android Chrome : menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil.
Le service worker met en cache l'application pour une utilisation hors ligne après le premier chargement.
Les données sont stockées localement dans le navigateur/appareil. Exportez régulièrement votre sauvegarde JSON.
Aucun compte, abonnement ou service payant. Pas de synchronisation cloud, pas de connexion automatique RENPHO/Fitbit/Health Connect.
